# 盤の裏の幽霊

2026-11-21 に入れた、詰将棋を解くたびに育つ幽霊の演出。決めたことと理由、調整するときに触る場所を残す。
サンプル（`npm run dev` 中に `/docs/mockups/ghost-bonus/`）で、連チャンや詰め方を選んで動きを確かめられる。

## 方針

- ポイント・レベル・称号・数字は出さない。積み上げて「もらう」ものは作らず、その場の演出だけにする。
- 反応から正解が分からないようにする。手の良し悪しでは変えず、手の種類（指す・取る・成る・打つ・応手）でだけ変える。攻方の手はすべて王手なので、王手への反応は毎回同じになる（`MIN_REPLY_DELAY_MS` と同じ考え方）。
- 考えている間は静かにする。動くのは指した瞬間と応手の瞬間だけ。ふだんは、ゆっくり小さく浮いているだけにする。
- 幽霊は盤の裏（木目の上・駒の下）にいて、前には出てこない。魂・きらめき・紙吹雪だけが駒の上を飛ぶ。
- ライブラリは使わない。WAAPI と CSS と、局面ごとの `AnimationScope`（`src/ui/effects/animationScope.ts`）で動かす。
- 設定の「幽霊を出す」で消せる（初期値は出す）。出さない人には幽霊の DOM を作らず、絵も読み込まない。出し直すと連チャン 0（駒台）から始める。

## 流れ

| いつ | 幽霊 |
|---|---|
| 開いたとき | 攻方の駒台の右端に座っている（盤の外なので、はっきり見える） |
| 指すたび | 手の種類で反応する（ふつうの手は舌なめずり・取ると驚く・成るとキラッ・打つとのぞき込む・応手はそわそわ）。王手を受けた玉の駒もびくっと震える |
| 玉が逃げたとき | ふわっとついて行く |
| 詰ませたとき | 玉から魂が抜け、幽霊が食べる（1回目は駒台から飛んで行く）。もぐもぐの最初のひと噛みで大きくなり、それから喜ぶ。結果のカードは今と同じタイミングで出し、食べる演出はカードと並行して続ける |
| 次の問題 | 盤の裏の幽霊が、そのまま次の玉のそばへ移動して隠れる。隠れる側（上下左右・斜め）は毎回ランダム |
| 不正解・ギブアップ | しょんぼりして、食べた魂が食べた色のまま1つずつ体から抜けて上っていく。1つ抜けるたびに1段しぼみ、照明も1段冷める。駒台の大きさまでしぼんだら、しょんぼり顔のまま垂れ下がってとぼとぼ駒台へ帰り、ため息の煙を吐く。連チャン 0 で駒台にいるときは、しょんぼりするだけ |
| 結果の後に 30 秒触らない | 眠る（Zzz）。どこかに触れると起きる。考えている間は眠らない |

## 連チャン

- アプリを開いている間だけ数え、保存しない（閉じれば 0 に戻る）。
- 数えるのは、解答を見ずに、この起動中に初めて解いた問題だけ。解答を見た後のクリアや、再挑戦で同じ問題を解いたときは、伸ばしも切りもしない（魂を食べる演出は出るが、育たない）。
  - 「履歴上で初めて解いた問題」にはしなかった。出題順「正解済みの問題を復習」で解く人の幽霊が育たなくなるため。
- 不正解・ギブアップで 0 に戻る。
- 連チャンが伸びるほど、幽霊が大きくなる（2問目は少し薄い）。玉を中心にした照明も 青白 → 青 → 紫 → 桃 → 金 と熱くなり、10連で虹色になる。10連で止め、以後は虹のまま。
- 食べ方は、連チャンで増える候補から毎回ランダムに選ぶ（吸い込む・飛びつく → 追いかける（5連〜）→ キャッチ（7連〜）→ 3つに分かれる（8連〜）→ 10連はたいらげる）。

## 効果音

音源ファイルは使わず、駒音と同じく Web Audio で合成する（`src/ui/sound.ts`）。設定の「効果音を鳴らす」でまとめて切り替える。幽霊の音は幽霊を出しているときだけ鳴る。

| いつ | 音 |
|---|---|
| 魂を口に入れた | ぱくっ（音程の落ちる短いポップ。ごちそうの残りなど続けて食べる魂は小さく） |
| もぐもぐ | ひと噛みごとに、こもった低い音 |
| 詰み | 連チャンで半音ずつ上がる（8連で5度上に止まる）。10連は和音を1音足す（`mateNotes`） |
| 魂が抜けていく | ひゅうっと上る細い音。抜けるほど低く小さくなる |
| 駒台に帰った | はぁ（帯域の下がっていく息の音） |
| 不正解・ギブアップで、上の「魂が抜けていく」が鳴らないとき（幽霊を出さない設定、連チャン 0 で駒台にいる、動きを減らす設定） | 幽霊の音ではない短い下降音（`Sound.miss`。simple-eigo / simple-whowhy の不正解の音と同じ）。不正解が音で伝わらないことがないようにする |

- 振動（`navigator.vibrate`）は使わない。以前試してうまく動かなかった（iPhone の Safari には API が無い）。

## 詰め方で変わる演出

詰ませた手順と局面だけから判定する（`src/game/finish.ts`、エンジンは使わない）。

| 詰め方 | 演出 |
|---|---|
| 最後の駒の種類 | 魂の色（歩は白・香は水色・桂は緑・銀は銀・金は金・角は紫・飛は赤。成駒は色が濃くなる） |
| 成って詰み | 魂がくるっと裏返って、成駒の色に変わる |
| 頭金 | 魂が丸い金の団子になって、ぽよんと弾む |
| 捨て駒 | 取らせた駒が、玉方の駒台からその駒の色の小さな魂になって戻ってきて、一緒に食べる |
| 合駒を取る | 合駒のあったマスからも、おまけの魂が出る |
| 手数 | 長いほど玉から出る魂が増える（5手で2つ、7手で3つ…）。7手以上は最初の魂も大きい |

- 「ときどき金の魂（ただの当たり）」は試したがやめた。魂の色に意味ができたので、ランダムの金が混ざると、金で詰ませたのか当たりなのか区別がつかないため。
- 両王手・空き王手・一間竜のような形は、まだ判定していない。両王手・空き王手は、利きの計算を TypeScript で書けば足せる。

## やめたこと（試して合わなかったもの）

- 結果のカードの縁に幽霊を乗せる：カジノらしさが出なかった。
- 詰んだ瞬間だけ盤を暗転させてボーナス画面にする、レベルアップ・メーター・宝石：ソーシャルゲームのようで、つまらなかった。
- 仲間の幽霊が増える：数より大きさで伝えるほうがよかった。
- 詰んだときに幽霊が前に浮かび上がってくる：毎回出てくるのは面倒だった。ずっと裏側にいるほうがよい。
- 問題ごとに盤の外から現れる：つながりがなかった。盤の上の幽霊が次の玉へ移動するほうがよい。
- 1問目の正解で背景（照明）だけを灯す：分かりにくかった。最初から駒台に幽霊を置くことにした。

## ファイル

| 場所 | 中身 |
|---|---|
| `src/ui/ghost/rules.ts` | 大きさ・照明の色・食べ方の候補・魂の色・隠れ場所・連チャンの数え方・逃げられたときのしぼみ方（DOM を使わない。`tests/ghostRules.test.ts`） |
| `src/ui/ghost/ghostView.ts` | 幽霊の DOM と演出。BoardView が持ち（出さない設定のときは作らない）、局面と着地を知らせる。詰み・不正解・眠るは App から呼ぶ |
| `src/ui/ghost/ghost.css` | 幽霊・魂・照明・Zzz の見た目 |
| `src/game/finish.ts` | 詰め方の判定（`tests/finish.test.ts`） |
| `public/ghost/*.webp` | 幽霊の表情と魂の絵（Codex の画像生成で作ったオリジナルの絵。512px・合計約 290KB） |
| `assets/app-icon.png` | アプリアイコンの原画（1024px・Codex の画像生成）。幽霊は隠し機能なので主役にせず、「詰」の駒の右肩から小さくのぞかせるだけにした。`npm run build:icons`（`scripts/build-icons.py`・Pillow が必要）で `public/icons/` と `favicon.ico` を作り直す。`favicon.svg` は手描きで、幽霊は描かない |

- 幽霊の層は `.board` の子に入れる。BoardView はマスを `.board` の子の並び順で探すので、マスの後ろに入れる。
- 視差効果を減らす設定では動かさず、居場所と大きさだけを変える。

## 調整するときに触る場所

- 濃さ：`ghostView.ts` の `density()`（盤の裏は `.spirit` 0.5 × `.spirit-pose` 0.44 ≒ 22%）。駒が読みにくければ下げる。
- 大きさ：`rules.ts` の `SIZES`（マス数）。
- 照明：`rules.ts` の `HUES` と、`ghostView.ts` の `paintLight()`。
- 眠るまで：`ghostView.ts` の `SLEEP_MS`。
- 絵を足すとき：元の `ghost-idle.webp` を渡して、体の形・位置・大きさを変えずに表情だけを変えるよう頼むと、差し替えても体が跳ばない。
